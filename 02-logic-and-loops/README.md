# Logic and Loops

This section introduces Python concepts used to make programs **store collections of data, make decisions, repeat actions, and work with text**.

We will gradually apply these concepts to build a word-scramble game called **Jargon Jumble**.

## What We'll Learn

| # | Topic                 | What We'll Learn                                        |
| - | --------------------- | ------------------------------------------------------- |
| 1 | **Lists**             | Store and work with collections of data                 |
| 2 | **Importing Modules** | Bring pre-written Python code into our programs         |
| 3 | **`if` / `else`**     | Make decisions based on conditions                      |
| 4 | **`while` Loops**     | Repeat code while a condition is true                   |
| 5 | **String Methods**    | Transform and clean up text                             |
| 6 | **Tuples**            | Keep related data together so it doesn't go out of sync |

## 🎮 Project: Jargon Jumble

As we learn each concept, we'll gradually build a word-scramble game.

The player will:

* See a scrambled word
* Try to unscramble it
* Ask for a **hint**
* **Skip** a word
* **Quit** the game
* Receive feedback for correct and incorrect guesses
* Keep track of their score
* See a final score when the game ends

### Example

```text
Round 1

Scrambled: DEELDAIN

Your guess (or 'hint' / 'skip' / 'quit'): hint
Hint: Of course we'll hit the ____, no problem! Well, within a couple of days. Maybe a week.

Your guess (or 'skip' / 'quit'): deadline
✅ Correct!
```

Eventually, all the concepts in this section will come together to create the complete game.

## Learning Approach

We will learn each concept **individually first**, using small examples and exercises.

Then we'll connect the concepts to the **Jargon Jumble** project.

```text
Lists
   ↓
Importing Modules
   ↓
if / else
   ↓
while Loops
   ↓
String Methods
   ↓
Tuples
   ↓
🎮 Jargon Jumble
```

## Key Goal

By the end of this section, we should understand how Python can:

* Work with collections of data
* Make decisions
* Repeat actions
* Manipulate text
* Keep related data together
* Combine these concepts into a working program
